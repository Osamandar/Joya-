# Бот напоминаний о медкнижках

Телеграм-бот на `aiogram`, который:

- регистрирует сотрудников через Telegram;
- хранит данные в Google Sheets;
- каждый день проверяет сроки окончания медкнижек;
- рассылает напоминания сотрудникам, администраторам и в рабочие группы.

## Файлы проекта

- `main.py` — запуск бота и планировщика
- `handlers.py` — обработчики регистрации и команд
- `scheduler.py` — ежедневная проверка сроков
- `google_sheets.py` — работа с Google Sheets (с TTL-кэшем)
- `config.py` — переменные окружения
- `setup_sheet.py` — подготовка структуры таблицы

## Команды для сотрудников

- `/start` — регистрация в боте
- `/whoami` — показать свой Chat ID и уровень доступа

## Панель администратора (кнопки)

| Кнопка | Действие |
|---|---|
| 📊 Статус | Сводка: всего сотрудников, сколько скоро истекает, просроченных |
| 📋 Список на 7 дней | Кто истекает в ближайшие 7 дней (с фильтром по подразделению) |
| 🚨 Просроченные | Сотрудники с истёкшей медкнижкой (с фильтром по подразделению) |
| 🔍 Проверить | Найти сотрудника и посмотреть его карточку |
| ✏️ Редактировать | Найти сотрудника и изменить поле |
| 🗑 Удалить | Найти сотрудника и удалить из таблицы |
| ▶️ Проверить сейчас | Запустить ежедневную рассылку вручную |

## Панель владельца (дополнительно)

| Кнопка | Действие |
|---|---|
| 👥 Администраторы | Список активных админов и заявок на доступ |

## Как работают напоминания

- за 7–6 дней: сообщение сотруднику и администраторам
- за 5–4 дня: сообщение сотруднику, администраторам и в группу подразделения
- за 3–1 день: сообщение администраторам и в главную группу
- в день окончания и после: строка помечается статусом и окрашивается в таблице

## Переменные окружения (.env)

```
BOT_TOKEN=        # токен от @BotFather
DEVELOPER_CHAT_ID= # Chat ID владельца
MAIN_GROUP_ID=    # ID главной группы для уведомлений
```

## Деплой на Railway

1. Подключить репозиторий в Railway
2. Добавить переменные окружения из `.env`
3. Загрузить `google_credentials.json` как переменную или файл
4. Railway запускает: `python main.py` (через `Procfile`)

## Деплой на VPS (systemd)

Заполнить пути в `joki-bot.service` и `deploy.sh`, затем:

```bash
bash deploy.sh
```
