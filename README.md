# Бот напоминаний о медкнижках

Телеграм-бот на `aiogram`, который:

- регистрирует сотрудников через Telegram;
- хранит данные в Google Sheets;
- каждый день проверяет сроки окончания медкнижек;
- рассылает напоминания сотрудникам, администраторам и в рабочие группы.

## Что есть в проекте

- `main.py` — запуск бота и планировщика
- `handlers.py` — регистрация и команды
- `scheduler.py` — ежедневная проверка сроков
- `google_sheets.py` — работа с Google Sheets
- `setup_sheet.py` — подготовка структуры таблицы

## Полезные команды

- `/start` — регистрация сотрудника
- `/whoami` — показать свой `Chat ID` и текущий уровень доступа
- `/request_admin` — отправить заявку на админ-доступ
- `/check ФИО` — поиск сотрудника по имени
- `/list 7` — кто заканчивается через 7 дней
- `/status` — сводка по срокам и проблемным записям
- `/edit поле | поиск | значение` — редактирование сотрудника админом
- `/admins` — список активных админов и заявок, только для владельца
- `/approve_admin 123456789` — выдать доступ админа
- `/approve_admin 123456789 owner` — выдать доступ владельца
- `/revoke_admin 123456789` — отключить админ-доступ

## Как работает напоминание

- за 7-6 дней: сообщение сотруднику и администраторам
- за 5-4 дня: сообщение сотруднику, администраторам и в группу подразделения
- за 3-1 день: сообщение администраторам и в главную группу
- в день окончания и после: строка помечается служебным статусом и красится в таблице
